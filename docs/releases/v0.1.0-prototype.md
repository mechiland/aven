# Aven 0.1.0 prototype ISO

A focused Fedora Atomic KDE desktop prototype: Dolphin Files and quick preview, Firefox, Thunderbird, Gwenview, and a Noto Sans foundation for Latin, Simplified Chinese and Traditional Chinese.

## Download the installer

Download these assets from this release into one directory:

- All four `Aven-Atomic-KDE-44-0.1.0-prototype-x86_64.iso.part-000` through `.part-003` files
- `ISO-PARTS.json`
- `reassemble-iso.py`

Run with Python 3:

```sh
python3 reassemble-iso.py
```

On Windows, use `py -3 reassemble-iso.py`. The helper verifies every part and the complete ISO before publishing its output. Use a normal filesystem with hard-link support; FAT/exFAT cannot run that publication step. The individual parts are not bootable.

**Result:** `Aven-Atomic-KDE-44-0.1.0-prototype-x86_64.iso` — 7,890,075,648 bytes.

**SHA-256:** `ae91559362ecfb87fa4f630882a78c41f699540d0ffda25ccea66c7be00e34e0`

Write the reconstructed ISO to a USB drive of at least 16 GB. This is an offline Anaconda installer, not a live desktop. Disk selection and first-user creation use Fedora's native interfaces. There is no preset account, password, automatic disk erasure or laboratory SSH access.

[Installation and reconstruction guide](https://github.com/mechiland/aven/blob/v0.1.0-prototype/docs/ISO.md)

## What is included

- Aven surfaces, window decoration, restrained motion and focused Dolphin defaults.
- Quick previews for images, PDF, text and common media; select a file and press **Ctrl+Alt+P**. Escape closes it; Enter opens the file in its configured application.
- Mature browser, mail and photo applications, integrated through fonts, chrome and defaults.
- Fedora `44.20260913.0` with its signed base, Fedora update origin, Atomic deployments and five persistent package requests. The local application layer is separately built and is not Fedora-signed.

ISO source commit: `9500b72a79320ce062a8b7360eac5806b142c93a`. The attached JSON manifest records all 150 embedded source files. Later repository commits contain verification evidence and release documentation.

## Verification

The exact ISO passed BIOS and UEFI optical boots, offline installation to a fresh disk, native first-user creation, automatic Aven first-login defaults and a second disk-only boot. Independent checks confirm the signed Fedora base/update origin, read-only Atomic root, SELinux, all 150 source files, 42 active font checks and 12 default associations.

Native smoke checks cover Files copy/rename/move/trash; image/PDF/SC/TC text/media preview; three Enter/Open handoffs; real Chinese HTTPS browsing, download and native file picker; local Chinese mail draft editing/save/reopen; and photo navigation/fullscreen. No real mail was sent.

The independent installed-ISO **1× visual review passes: 8.27 overall, 8.5 Chinese typography**, with a yes on the three-second comparison. Two nonblocking details remain: initial Files rows are denser than after visiting grid, and a taller photo filmstrip reduces the main image area. The current full fractional-scale and motion matrix was not rerun; the round-4 matrix remains historical evidence.
