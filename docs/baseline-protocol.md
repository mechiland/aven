# Paired evidence protocol

## Ground rules

Use the official Fedora Kinoite 44 install ISO (44-1.7), verified with the Fedora
44 signing key and SHA-256. Boot it before any Aven styling is applied. Record
the OSTree commit and installed application versions in capture sidecars.

The VM harness adds only an automation user, SSH, autologin and passwordless sudo.
These are laboratory facilities, not Aven distribution defaults. Keep stock
visual preferences untouched. Capture an initial stock desktop immediately.
The unattended lab also disables idle screen locking for capture sessions and
marks the already-created Kickstart user as configured. This changes no login
or lock-screen appearance and is not an Aven product default.

If an app required by the scenarios is absent, add its stock package and record
the addition. Fonts, codecs and language support needed for a fair comparison
must be available in both variants. Preserve a baseline deployment before Aven
configuration. If stable updates are needed for dependency compatibility, update
stock first and recapture the paired scenarios on that exact version.

The initial ISO's bundled Gwenview Flatpak failed to launch with missing
`libraw.so.24` (exit 127), witnessed through a normal Dolphin image open. The
version-matched comparison uses Fedora's native Gwenview package on both guests.
The initial ISO supplies no mail client; native Thunderbird is added to both.
Initial screenshots with the `-initial` suffix retain the untouched 44.1.7
appearance; the final comparison baseline uses the stable 44 update.

## Content

Run `scripts/sync-guest.py --guest stock` on the host and
`python3 ~/aven/scripts/seed-fixtures.py` in the guest. Mail tooling supplies a
fictional local mailbox with SC, TC and English messages; no external account
or sending is needed. Photos keep licensed original bytes, rotation metadata
and source attribution. The document fixture is original fictional material.

The PDF fixture is generated by Chromium's print engine to embed the installed
Noto CJK fonts and rendered with Poppler for visual QA. This rendering is only
fixture validation, never OS visual evidence.

## Required scenes

1. Desktop, no open app, same scale and viewport.
2. Dolphin home and sidebar; details and icons views.
3. `Documents/日常 · Everyday` with mixed documents, images and media.
4. Native stock preview (information panel / associated viewer), then Aven preview
   for image, PDF, Chinese text and media. Show the actual interaction used.
5. Firefox with a real web page plus controlled SC/TC reading and download/upload.
6. Thunderbird message list, SC and TC message, draft compose.
7. Gwenview thumbnail browsing, fitted landscape, EXIF portrait and transparency.
8. Noto specimen in a browser and Chinese application interfaces at 100%, 125%,
   150% and 200%. Locale-tagged web prose alone cannot prove Qt UI fallback.

Use `scripts/capture.py` for unmodified QEMU framebuffer PNGs and provenance.
Do not crop out defects or replace the contents of a captured application.
Evidence sidecars distinguish a declared scale/locale from the actual display
configuration probe. Record screenshot inspection separately.

## Operations and motion

Exercise a disposable copy of the fixtures: open folders, breadcrumbs, sidebar,
grid/list, selection, copy/move, rename (including Chinese names), trash and
restore, default-app launch, preview toggle, Escape focus return, download and
file chooser, mail draft save, and next/previous photos. Compare checksums after
copy/move. Never send mail for a fixture test.

Observe or record window open/close, Alt+Tab, menus/popovers, preview and image
transitions, and overview. A static screenshot gives no evidence of frame pacing
or smoothness. Distinguish VM limitations from a measured implementation defect.

## Critic gate

The independent critic inspects matching stock/Aven evidence and scores all nine
user-requested categories. Every category needs cited evidence and limitations.
Missing coverage stays unscored. Overall is the arithmetic mean of all nine
scores; no hiding weak categories with selective weighting.

Pass requires overall >=8, Chinese typography >=8.5, and **yes** to:
“If shown both desktops for three seconds, is Aven unmistakably different and
more refined?” The root integrator records the result in `docs/STATUS.json` and
fixes the weakest concrete issues before another build/boot/capture round.
